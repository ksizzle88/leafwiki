# /cleanup — Session Artifact Cleanup

Arguments: `$ARGUMENTS`

If arguments contain `--dry-run` or `dry`, **report only — do NOT delete or move anything**. Show what would happen with `[DRY RUN]` prefix on each action.

Scan the workspace for ephemeral artifacts, temp files, analysis outputs, and unsaved context. Persist what matters, clean up what doesn't.

## Memory System Reference

Memory lives at `~/.claude/projects/-workspace/memory/` with this hierarchy:

```
memory/
├── MEMORY.md              ← top-level index (wiki-style links)
├── hot/                   ← always loaded at session start
│   ├── identity.md        ← who Keith is, who Claudio is
│   ├── active-context.md  ← current projects, in-progress work
│   └── last-session.md    ← auto-generated by sleep hook
├── warm/                  ← loaded on demand
│   ├── feedback/index.md  ← corrections, confirmations
│   ├── projects/index.md  ← project decisions, architecture
│   └── reference/index.md ← external systems, tools
├── cold/index.md          ← archived, rarely needed
└── self/                  ← Claudio's own documents
```

**Rules:**
- Use wiki-style links: `[Title](path.md) — description`
- One topic per file, descriptive filenames
- Indexes are flat lists of links, not paragraphs
- Frontmatter on every memory file: `name`, `description`, `type` (user/feedback/project/reference)
- Update indexes when adding files
- Don't duplicate — check before writing

## Step 1: Find Artifacts

Search for common artifact patterns:
- `/tmp/claude*` — temp files from hooks and subagents
- `/workspace/**/*.log` — log files (not in .git or node_modules)
- `/workspace/**/*report*`, `/workspace/**/*analysis*`, `/workspace/**/*snapshot*` — analysis outputs
- `/workspace/docs/` — ad-hoc docs that may belong in memory
- `**/.dev/` — script outputs, JSON dumps, state files
- Orphaned `.tar.gz`, `.jsonl`, `.bak.*` files in the workspace
- Any file modified today that's not tracked by git and not gitignored
- Stale files in `/workspace/backup2/` or similar temp backup dirs

## Step 2: Triage Each Artifact

For each artifact found, classify it as one of:

| Classification | Destination | When |
|---|---|---|
| **Memory — hot** | `memory/hot/` | Active context, identity, session state |
| **Memory — warm/projects** | `memory/warm/projects/` | Architecture decisions, completed work, post-mortems |
| **Memory — warm/feedback** | `memory/warm/feedback/` | Behavioral corrections, confirmed patterns |
| **Memory — warm/reference** | `memory/warm/reference/` | External system pointers, credentials locations |
| **Memory — cold** | `memory/cold/` | Old/completed work worth archiving |
| **Artifact** | `/workspace/.dev/artifacts/` | Scripts, data dumps, reusable outputs |
| **Delete** | (removed) | Temp files, stale logs, duplicate backups, build cache |
| **Skip** | (leave in place) | Files that belong where they are |

## Step 3: Execute (unless --dry-run)

- Delete everything classified as Delete
- Move Artifact files to `/workspace/.dev/artifacts/`
- Write Memory files with proper frontmatter and wiki-style links
- Update the relevant memory index file for each new memory
- Update `hot/active-context.md` if project state changed

## Step 4: Verify Gitignore

Check that artifact directories are gitignored:
- `.dev/artifacts/`
- `backup2/`
- Any new artifact directories created

If not gitignored, add them.
